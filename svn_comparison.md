1. Почему в Git ветвление "дешёвое", а в SVN — "дорогое"?
    В Git ветка — это небольшой указатель на коммит, поэтому её создание и переключение требуют минимум ресурсов. В SVN ветвление обычно связано с копированием дерева файлов в репозитории, поэтому оно требует больше операций и места.
2. Можно ли в SVN сделать коммит без интернета? Почему?
    Нет, SVN использует централизованную модель, поэтому коммит должен быть отправлен на сервер. В Git коммит создаётся локально, поэтому интернет для него не нужен.
3. В каких сценариях SVN до сих пор может быть предпочтительнее Git?
    SVN может быть удобнее там, где нужен централизованный контроль версий, строгий контроль доступа к отдельным каталогам и простая модель работы с единым сервером. Также он может использоваться в старых корпоративных проектах, где уже построена инфраструктура вокруг SVN.
